# 0001 — Arbitrate by what it proves to a client

## Decision

Every choice is settled by what it proves to a prospect, not by what is most modern.

## Reason

The ecosystem is a commercial showcase for a freelance activity. Clients run Xamarin applications in production, so serving them is market proof and Xamarin stays in scope.
